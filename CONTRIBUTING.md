# Contributing

Thank you for your interest in contributing! This repository serves as my GitHub profile README and is primarily for showcasing my work. However, contributions are welcome for:

## Welcome Contributions
- **Typos & Grammar** — Fix spelling, punctuation, clarity
- **Broken Links** — Update dead links in README or workflows
- **Accessibility** — Improve alt text, contrast, semantic HTML
- **Workflow Improvements** — Optimize GitHub Actions, add new dynamic sections
- **Design Polish** — Refine Apple aesthetic, color tokens, spacing

## Not Accepted
- Feature requests for new sections (this is a personal profile)
- Changes to personal information (bio, links, projects)
- Non-trivial refactors without discussion

## How to Contribute
1. Fork the repository
2. Create a branch: `git checkout -b fix/typo-readme`
3. Make your change
4. Verify it renders correctly locally (open README.md in browser)
5. Submit a PR with a clear description

## Local Preview
```bash
# Simple preview - open in browser
open README.md

# Or use a Markdown preview extension in VS Code
# Cmd+Shift+V (Mac) / Ctrl+Shift+V (Windows)
```

## Code Style
- **Markdown**: Follow GitHub Flavored Markdown
- **HTML**: Semantic, accessible, minimal inline styles
- **GitHub Actions**: YAML with 2-space indent, descriptive step names
- **Commits**: Conventional Commits (`fix:`, `feat:`, `chore:`, `docs:`)
